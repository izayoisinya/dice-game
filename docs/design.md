## 1. コンセプト・全体方針

### 最重要コンセプト
**ダイスの出目でついた不利を、采配でいかに覆すか。**

仕様やバランスで迷ったときは、この方針を優先して判断する。

- 戦力差があっても逆転できる余地を残す。ダイスで勝敗が決まり切るバランスにはしない
- 逆転の筋道の例: 雑兵で相手の総大将を削り、総大将どうしの勝負を有利にする（総大将討ち取りで勝利）
  - プロトタイプで確認済み: 3d6=3（4体・コスト400）の軍が、7（8体・コスト600）の軍に総大将どうしの勝負で勝つ展開が起きている
- 今後の要素（スキル・士気・地形・手動操作）は、「不利側が采配で取れる手」を増やす方向で設計する

### 全体方針
- ターン制戦略シミュレーション（ブラウザ / HTML・JS、外部ライブラリなし）
- 着想: 家庭教師ヒットマンREBORN! 未来編の「チョイス」
- CPU 戦メイン（将来的に 1vs1・複数陣営も視野）
- 操作: **手動プレイ**（編成時の総大将の振り分けも、戦闘中のユニット操作もプレイヤーが行う）。検証用にオート観戦モードも残す ✅
- 1試合にしっかり時間がかかる想定。空き時間に少しずつ進められるよう、ゲームの状態は自動保存され、タスクキルしてもリセットされない ✅

## 1.5 全体構造: 戦略レイヤーと戦術レイヤー（構想） 📝

このゲームは軍隊の戦略シミュレーションで、2層からなる。**今作っているのは戦術レイヤー**（戦局で部隊どうしがぶつかったときの戦闘）。

### 戦略レイヤー（軍全体の編成・運用）
- **各兵種の総数をダイスで決める**（例: 剣兵 1000人、槍兵 600人 …）
- それを**何部隊に分けるかは自由**（剣 1000人を 5部隊に割るのも 10部隊に割るのも自由）
- **各部隊の兵種構成も自由**（剣・槍・弓・盾・騎をバランスよく混ぜても、剣だけの部隊にしてもよい）
- **兵長**: 対応する兵種の部隊に編成すると、その部隊の能力が上がる（例: 剣兵長を剣兵の多い部隊へ）
- **指揮系統**: 部隊には副将がいて、その下に兵長、その下に雑兵。**副将のいない部隊も作れる**
- 総大将は軍全体のトップ

### 戦術レイヤー（部隊どうしの衝突 = 現在のプロトタイプ）
- 戦局で部隊どうしがぶつかったときの戦闘を、マス目の戦場で行う
- 現在のプロトタイプの「軍」は、戦略レイヤーでいう1部隊（または衝突した複数部隊）にあたる

### 決まったこと
- **戦局の決着**: その戦局でお互いの**最も階級が上の者**を倒したら強制決着（全滅でも決着） ✅
- **撤退**: その戦局の大将にあたるユニットを操作するとき、「撤退」コマンドを選べる ✅（手動プレイ）
  - **総大将の撤退 = その時点で自軍の敗北** ✅
  - 副将などの撤退は、その隊が戦場から退く扱い（隊は残る） ✅
- **戦略マップ**: シミュレーション RPG 的なマップ。部隊に編成した兵数が多いほど、移動に時間がかかる 📝

### 隊の構成（決まったこと）
- **呼び名**: 旧「部隊長」は「兵長」に統一。兵長を同じ兵種の兵士の駒と一緒に運用すると**隊長**になる
- **副将と兵長の人数はダイスで決める** ✅（下の「軍の編成画面」）
- 総大将のいる隊 = **本隊**、本隊から分けた隊 = **分隊**
- 各隊の構成:
  - **隊長クラス**: 総大将（本隊）、副将（分隊。副将のいない分隊も可）
  - **各兵種の兵長**: 兵長1人で1駒
  - **各兵種の兵士**: 1駒の人数は調整可（最低10人）
- **兵長と兵士（兵種ごとの隊長）**: 兵長は、同じ隊にいる**同じ兵種の兵士の駒**の隊長になり、その駒にバフが付く（剣兵長 → 剣兵の駒）。兵長がいない兵種の駒は隊長なし（バフなし）
- **隊の隊長**:
  - 本隊 = 総大将
  - 分隊 = 副将クラス
  - 小隊 = 副将または兵長
- **統率力**（副将・兵長の新パラメータ）: 隊に編成できる兵士の駒の上限が統率力で決まる。統率に優れた副将・兵長と、戦闘向きの副将・兵長のような個性を出す
- **砦**: 副将クラスが常駐する必要がある。常駐する副将が倒されると陥落し、相手の砦になる → 副将は分隊にも砦にも使うので、人数は多めにする。兵長はさらに多め

### 軍の編成画面（戦略レイヤーの第一歩） ✅🧪
**操作の流れ**: 上部の「🎲 戦力集結」（ダイスで軍全体の人員を決める）→ 編成パネルで本隊・分隊に割り振る（「おまかせ編成」も可）→ 隊の「出陣」で相手を選ぶ →「⚔ 戦闘開始」。「↺ リセット」は戦闘も軍（編成・戦略マップ）もすべて消して最初に戻す（確認あり）。決着がついた軍は、戦力集結かリセットで作り直す。
以前の上部「編成」（3d6 のランダムな軍どうしの戦闘）は画面から外した（シミュレーション用に `formArmy` は残している）。

画面上部の「軍の編成」。ダイスで軍を作り、隊を組んで、CPU軍の隊と戦わせる。損害は軍に持ち帰る（`localStorage` に自動保存）。

| 項目 | 決め方 |
|---|---|
| 各兵種の総数 | 兵種ごとに 1d20 × 100（100〜2000人） |
| 副将の人数 | 2d4 + 2（4〜10人） |
| 兵長の人数 | 兵種ごとに 1d3 + 1（2〜4人）。1d4+2 から減らした（隊に入らない兵長は、将来の暗殺者などの単独行動に回す想定） |
| 兵長の統率力 | 1人ずつ 1d5 + 1（2〜6） |
| 総大将・副将の統率力 | 振り分けで買う。基本3、+1ごとに40pt、最大15（初期値: 総大将7・副将5）。指揮枠になる |

- **隊**: 本隊（隊長＝総大将）、分隊（隊長＝副将）、小隊（隊長＝兵長）。隊長にしていない副将・兵長から新しい隊を作れる
- **配下の将**: 隊には隊長のほかに副将・兵長を入れられる。副将を全員分隊長にする必要はなく、「本隊に総大将＋副将数名」も可。副将が入れるのは総大将・副将が率いる隊だけ（兵長が率いる小隊には兵長だけ）
- **斥候・暗殺者**: どの隊にも入れられる（隊長にはなれない）。駒の上限には数えない。おまかせ編成では斥候を本隊から1人ずつ、暗殺者を分隊に配る
- **統率力で決まる2つの上限**（隊長の統率力だけ。配下の将の統率力は足さない）。兵長の統率力は、小隊を率いるときや隊長を継いだときに効く
  - **率いる人数** = 統率力 × 200人分（`LDR_MEN`）。兵士は1人 = 1、配下の兵長 = 100人分・副将 = 150人分（階級のコストで換算: 兵長 1000・副将 1500 ÷ 兵士1人 10）。斥候・暗殺者は 0（単独で動く者）
  - **駒の数** = 統率力（細かく分けすぎないように）
  - 経緯: はじめは兵士の駒の数だけを数えていた → 副将・兵長を無制限に入れられた → 駒1つ = 枠1 にしたが、10人の駒も100人の駒も同じ扱いになった → 人数で数えるように
  - おまかせ編成: 本隊に残す副将は1人まで（統率7以上のとき）、ほかの副将はそれぞれ分隊を率いる。兵士は率いる人数の75%までを目安に配り、残りで兵長・副将を連れる。それでも余った兵士は、予備の兵長が小隊を組んで率いる（最大3隊）。率いきれない兵長は予備に残る
- **統率オーバー**: 隊長が倒れて統率力の低い将が継ぐと、上限を超えることがある。画面に表示し、駒は追加できない。戦略マップでは移動が遅くなる予定 📝
- 全兵種をそろえる必要はない（盾兵のいない隊、騎兵のいない隊なども可）。駒を細かく分ける必要もない
- **兵長の隊長バフ**: 同じ戦場に同じ兵種の兵長が健在なら、その兵種の兵士の駒は ATK / DEF +10%（`SERGEANT_BUFF`）。通常の「編成」ボタンの戦闘にも効く
- 副将の振り分けは総大将と同じ仕組み（コスト1500・スキル1つ）。「振り分け」ボタンで編集
- **自動配置（隊はそのまま）**: 自分で作った隊の数と隊長は変えずに、配下の将・斥候・暗殺者・兵士を配り直す。小隊（兵長が隊長）は隊長の兵種＋0〜1兵種、兵士の割合は 本隊 2 : 分隊 1 : 小隊 0.5。ほかはおまかせ編成と同じ
- **おまかせ編成**（CPU軍は常にこれ）:
  - 副将の半分が分隊を率い、残りは本隊に残る
  - 分隊は得意な兵種を2〜4つ選ぶ（全兵種はそろえない）。本隊は全兵種
  - 兵長は各隊の兵種に1人ずつ（本隊から順に）。余った兵長は予備
  - 兵士は本隊 2 : 分隊 1 の割合で配り、100人前後の駒にする。統率力に収まらなければ駒を大きくする
- **出陣**: 自軍の隊と相手（CPU軍の隊）を選んで戦術戦闘へ。布陣しきれない駒は出陣せず残る
- **結果の持ち帰り**: 生き残った駒は残った人数で隊に戻り、減った人数は総数からも引く。倒れた将は軍から外れる
  - 分隊・小隊の隊長が倒れたら、配下の副将（いなければ兵長）が隊長を継ぐ。誰もいなければ隊は解散し、兵は予備に戻る
  - 総大将が倒れる・撤退する = その軍の敗北。副将・兵長の撤退はその戦局だけの敗北（隊は残る）
- 検討: 戦略マップがないので、今は好きな相手の隊（本隊も）を直接選べる。戦略マップができたら、隣り合った隊どうしだけが戦う形にする

- **昇格**: 条件を満たした兵士が兵長に進化する
- **クーデター**: 総大将の統率力が低く、副将の統率力が高いと反乱が起きる、などの要素もありうる 💡

### 兵数と駒（決まったこと）
- 各兵種の総数はダイスで **100〜1000人**（想定。平均 600 前後）
- **1駒に何人を割くかはプレイヤーが決める**（100人を 5駒に分けても、100人 1駒で使ってもよい）。分けると1駒の戦力は落ちるが、取り回しがしやすくなる
- 雑兵の駒は**人数**を持ち、将（兵長・副将・総大将・兵長）は人数で数えない個人の駒（武将とその親衛隊のイメージ）
- 分けすぎを防ぐ仕組み:
  1. **指揮できる駒の数に上限**: 隊長と兵長の統率力の合計まで ✅
  2. **1駒の最低人数**: 新しく作る駒は100人以上（`MIN_PIECE`）。戦闘で減った駒は10人（`MIN_TROOPS`）まで残る ✅
  3. **大きい駒の利点**: 人数が多いほど心強く DEF が上がり、手数も増える ✅

### 駒の人数の仕組み（戦術レイヤー） ✅🧪
- 今の雑兵のステータスを **50人の駒**の強さとする（`BASE_TROOPS`）
- **HP は人数に比例**。攻撃を受けると人数が減る（表の名前欄に「(48人)」のように表示）
- **1回の威力と手数（行動ゲージのたまり方）は、それぞれ √(今の人数 ÷ 50) 倍** → 総火力は人数に比例。人数が減ると弱くなる
- **心強さ**: 人数が倍になるごとに DEF +5%（半分になるごとに −5%）、±10% まで（`SIZE_DEF_BONUS` / `SIZE_DEF_CAP`）
- 損害は人数として戦略レイヤーに持ち帰る想定 📝

**分け方の比較**（同じ兵種の総数400人どうし、総大将は「将」バランス型、200戦ずつ。左側の勝率）

| | 剣兵 | 槍兵 | 弓兵 |
|---|---|---|---|
| 1駒(400人) vs 16駒(25人) | 65% | 66% | 56% |
| 1駒(400人) vs 4駒(100人) | 61% | 62% | 70% |
| 16駒 vs 4駒 | 46% | 37% | 39% |

- 心強さボーナスが ±20%（倍ごと ±10%）だと槍兵で 1駒 vs 16駒が 78% と偏ったため、半分にした
- それでも、まとめた方がやや有利（「戦力の集中」）。小さい駒は倒されるたびに戦力が欠けていくため。細かく分ける利点（包囲・回り込み・足止め・戦略マップでの速さ）は手動プレイや戦略レイヤーで活きる想定
- ふだんの戦闘（全駒 50人）では、人数が減ると弱くなる以外は従来と同じ。兵種どうしのバランス・逆転率もほぼ変わらず

## 1.6 戦略マップ（最初の版） ✅🧪
`strategy.js`。軍の編成のあと「🗺 出陣（戦略マップへ）」で始まる。

**決まったこと**
- 時間の進め方: **交互ターン**（SRPG方式）。リアルタイムも魅力だが問題が多いので見送り
- マップ: **ダイスで決める**。今後の目標はランダム生成で、きれいな四角以外の形にもすること 📝
- 伝令（連絡役）: 今は扱わない

**ルール**
- 広さ: 幅・高さとも 12 + 2d4（14〜20）。地形は 平地（移動コスト1）・森（2）・山（3）・川（通れない）・浅瀬（2）。森と山は塊で置き、川は半分の確率で中央付近を横切る（浅瀬が2〜3か所）。両軍の本陣（陣）は上下の端の中央。両本陣と全部の砦がつながるまで作り直す
- 砦: 1d3+1 か所（中立）。隊が入ると自軍のもの（守備隊がいなければ敵の砦も奪える）。斥候・暗殺者だけでは奪えない
  - **駐留**: 自軍の砦にいる隊から、配下の副将（隊長以外）を砦に残せる → 「守備隊」（動かない、視界3）。隊は隣のマスへ出る
  - 守備隊が戦闘に負けるか全滅すると砦は陥落し、相手のものになる
- 隊の移動力: 兵数 〜200人 4 / 〜500人 3 / 〜1000人 2 / それ以上 1。統率オーバーなら −1。単独の斥候 6・暗殺者 4。地形のコストを払って進む。移動力が足りなくても隣の1マスへは必ず進める。敵の隊は通れない、味方の隊は通れるが止まれない。1マスに1隊
- 出陣時、どの隊にも入っていない斥候・暗殺者は**単独の隊**として出る
- **攻撃**: 敵の隊に隣接して攻撃すると戦術戦闘になる（攻撃は移動の前でも後でも可。単独の斥候は攻撃できない）。戦術戦闘の勝敗と損害を持ち帰り、「戦略マップに戻る」で反映
  - 全滅（隊長が倒れて継ぐ将もいない）した隊は消える。負けた隊は相手から1マス退く
- **視界**（上部の「視界（霧）」で切り替え）: 隊 3マス / 単独の斥候 6 / 単独の暗殺者 2 / 守備隊 3。単独の暗殺者は隣接しないと見えない（斥候なら2マス）
- 決着: どちらかの総大将が倒れるか撤退したら終わり
- 出陣後の編成の変更は、自軍の砦・本陣での再編成で行う（下の「砦の効果」）

**砦の効果** ✅🧪（砦のマスをクリックすると説明が出る）
- ① **守り**: 自軍の砦の上か隣にいる隊（守備隊を含む）は、戦術戦闘で DEF +20%（`FORT_DEF`。戦闘ログに表示）
- ③ **再編成**: 自軍の砦か本陣の上・隣にいる隊を選ぶと「🏯 ○○で再編成」。そこに集まっている隊どうしで、兵士の駒・配下の将の受け渡し、配下の副将・兵長を隊長にした分割（拠点に最も近い空きマス・3マス以内）、隊ごとの合流ができる（行動は使わない）。**本陣では予備の兵・将も使える**（砦では使えない）。守備隊にも兵士の駒を入れられる（守備兵）
- ④ **見張り**: 守備隊がいなくても、自軍の砦の周囲3マスが見える（単独の暗殺者は隣接のみ）
- ② 兵の補充（回復）は、再編成で代用できてしまうので見送り / ⑤ 砦の制圧で勝ち は「そういうモード」として作るならあり 💡

**罠（斥候）** ✅🧪
- 斥候のいる隊（単独の斥候、または配下に斥候がいる隊）が、隣の空いたマスに罠（落とし穴）を仕掛けられる（行動を使う）。川・砦・本陣・罠のあるマスには置けない
- 数の上限: 生きている斥候1人につき2個（軍全体）
- 相手には、仕掛けたマスに乗るまで分からない。斥候のいる隊が2マス以内に近づくと見つける（見つけた敵の罠は 🪤 で表示され、そのマスには入らない）
- 斥候のいる隊が知らない罠の上を通ろうとすると、手前で気づいて足を止める（かからない）
- 見つけた敵の罠に隣接していれば「罠を解除」できる（行動を使う）
- 単独の暗殺者は罠にかからない
- かかった隊: 兵士の駒がそれぞれ人数の10%（騎兵は20%）を失い、そのマスで止まって行動が終わる。罠は消える
- CPU: 斥候のいる隊が、ときどき（1/3）自軍の本陣より前の、プレイヤーの本陣へ向かう側のマスに仕掛ける。見つけた罠が隣にあれば解除する

**CPU の動き**
- 隣接して見えている自軍の隊のうち、「相手を囲んでいるCPUの隊の戦力の合計（兵数 + 将1人150）」が相手の 0.7 倍以上なら攻撃（守備隊・斥候にはいつでも）
- それ以外は、自軍のものでない砦（ほかの隊が狙っていない近いもの）→ 見えている敵 → プレイヤーの本陣 の順に目標にして進む。自軍の砦に余った副将がいれば駐留させる
- 本隊は本陣で待つ。砦をすべて押さえたか、ほかに動ける隊がいなくなったら出てくる
- 見えている敵を目指して隣まで来たら、戦力で劣っていても攻めかかる（以前は 0.7 倍の条件を満たさず、隣で睨み合ったまま動かなくなることがあった）
- 自動プレイ（簡単なボット対CPU）で、最後まで決着がつくことを確認（自軍勝ち・負けの両方）

## 1.66 総大将と統率力 ✅
- **総大将は統率力が安い**: 統率力1あたり 20pt（副将は 40pt）。統率力あってこその総大将なので、軍を率いても脆くなりにくい（`LDR_COST_COMMANDER`）
- **総大将の器**: 総大将の統率力が基本値（3）より1高いごとに、士気（総大将の周囲3マスの味方の ATK / DEF）の効果 +0.5%。統率12なら 5% → 9.5%（`MORALE_PER_LDR`）。本人が脆くても、軍として強くなる
- 振り分けのポップアップに **射程 強化**（+0 / +1。将の射程は 1 → 2 まで）を戻した。射程は固定ではなく、高いポイントで買える
- 副将の役割: 統率を捨てて単体の殴り合いに強い武将にもなれる（狙いどおりのトレードオフ）
- 💡 副将の統率力が高いとクーデターが起きる、は面白いが自滅要素になりやすいので保留
- **将の武器（刀 / 弓）**: 総大将・副将は振り分けで武器を選べる。弓を選ぶと兵種が「弓将」になる
  - 弓将: 射程4（強化で最大6）・最適距離3・後衛（前衛より前に出ない）・狙い撃ち。隣接されると命中 ×0.6。三すくみの相性なし
  - 射程の分のコストを全額払うと脆すぎて、刀の副将との同条件の模擬戦で勝率2〜10%だった。武器は「用途の違い」なので射程のコストを軽くする（`weaponDiscount: 55`）。45で32〜42%（150戦）、60で65%（60戦）→ 55
  - プリセットに「弓将型」（射程4・遠隔狙撃）。ランダムでは4人に1人くらいが弓
- **武器は5種類**（刀 / 槍 / 弓 / 盾 / 馬）。将の兵種はどれも三すくみの相性を持たない（与える側も受ける側も ×1.0）
  - 槍 → 槍将: 射程2・突き/薙ぎ払い。`weaponDiscount −10`
  - 盾 → 盾将: 堅守（受けるダメージ減）。庇うは持たない（将が身代わりになって倒れると負けるため。庇うつきは模擬戦で勝率 13〜71% と極端に振れた）。`−10`
  - 馬 → 騎将: SPD 130（移動 +1）・突撃。足の分の固定枠が重いので `+45`（割引なしは勝率5%）
  - 副将どうし（兵士6駒ずつ、相手は刀、250戦）: 刀 48% / 槍 49% / 弓 60% / 盾 57% / 馬 43%
  - ランダムでは半分が刀、残りを槍・弓・盾・馬で分ける

### コスト制ステータス ✅🧪
- **ステータス値の合計 = 階級のコスト**
- 射程は強力なので、RNG だけは **1 上げるごとに 3 ポイント**払う
  - `rngCost(RNG) = (RNG × 3 − 2) × 10`（RNG1=10, 2=40, 3=70, 4=100, 5=130）
- 上の階級は雑兵プリセットをコスト比で拡大（兵長 ×2、総大将 ×4）。射程の値は変わらず、射程に払うコストも同じ比率で上がる
- **数値は設計ログ・Gemini 案の10倍スケール**（コスト 500 / 1000 / 2000）。1ポイントの刻みを細かくして調整しやすくするため。設計ログの「雑兵は1〜10スケール」は、合計を揃えると各値が上限付近に集中して兵種差が出ないため、上限は設けていない 🧪

### 総大将専用の兵種「将」 ✅🧪
- 総大将は必ず「将」。兵として編成される兵種（剣・槍・弓・盾・騎）からは選ばない
  - 兵種ランダムだと、総大将戦で兵種差・相性が増幅され、総大将の兵種のくじ引きで勝敗が決まっていたため（9. の記録）
- 三すくみの相性を持たない（与える側も受ける側も ×1.0）
- 固定枠の基準値: SPD 90 / ACT 70 / RNG 1（剣と槍の中間）。HIT 85%
- 騎兵らしさは「騎乗」（移動力の強化）で、盾兵らしさは将来の指揮官スキル（鉄壁の構えなど）で表現する
- 副将（コスト150）も同じ「将」を使い回す想定

### 総大将のステータス振り分け ✅🧪
- **固定枠**: SPD / ACT / RNG は「将」の固定値。固定枠の分は階級倍率（×4）分のコストを払う（SPD 90 + ACT 70 + RNG1 の 10 = 170 × 4 = 680）
- **強化**: 固定枠を上げるには、固定枠と同じく階級倍率分（総大将は1ポイントにつき4ポイント）が必要（SPD・ACT は +50 まで）（`UPGRADE_MULT` = 1.0）
  - 反撃の導入で騎乗型が 0〜1% まで落ちたため、1.5倍 → 1.0倍に下げた
- **射程の上限**: 兵種の基本値の1.5倍（切り上げ）まで。剣 1→2 / 槍 2→3 / 弓 5→8 / 将 1→2。弓より射程の長い剣などが生まれないようにするため
  - 距離補正の表にない距離（弓の6〜8など）は、表の最も遠い距離の値を使う
- **自由枠**: 残り（1320）を HP / ATK / DEF に自由に振り分ける
  - 各ステータスは自由枠の **20%〜50%**（`ALLOC_MIN` / `ALLOC_MAX`）。HP 0 のような極端な振り方を防ぐ。範囲外を指定した分は、範囲内のステータスへ比率どおりに配り直す
- 全部を自由にすると強い型が固定化しやすいため、テンポ系（足・手数・射程）は固定にしている
- 手動プレイではプレイヤーが振り分ける想定。下の型はその例

| 型 | HP : ATK : DEF | 強化 | スキル | 将での値（HP/ATK/DEF・移動力） |
|---|---|---|---|---|
| バランス型 | 4 : 3 : 3 | — | 一斉指揮 | 528 / 396 / 396・3 |
| 攻撃型 | 3.5 : 3.5 : 3 | — | 強撃 | 462 / 462 / 396・3 |
| 防御型 | 3.5 : 2.5 : 4 | — | 鉄壁の構え | 462 / 330 / 528・3 |
| 騎乗型 | 4 : 3 : 3 | SPD +40（移動力 3→4） | 一撃離脱 | 428 / 321 / 321・4 |

⚠️ **型どうしのバランスは調整中**（9. の「総大将の型の差」）。スキル導入で騎乗型・防御型は持ち直したが、攻撃型がまだ強い。オート時は両軍とも「バランス型」に固定している（`AUTO_BUILD`）。

### スキル ✅🧪
- **総大将は2つ、副将は1つまで**所有できる（`SKILL_SLOTS`）。1つ目は無料、2つ目以降は自由枠のポイントを払う
- 能動型: 行動中に条件を満たすと自動で使う（オート時）。使うと待ち時間（自分の行動回数）の間は使えない。スキルの使用は行動を消費しない
- スキルの種類は後々増やしていく

| スキル | 値段 | 待ち | 効果 | オート時に使う条件 |
|---|---|---|---|---|
| 強撃 | 250 | 3 | その行動の初撃の ATK ×1.15 | 攻撃するとき |
| 鉄壁の構え | 200 | 3 | 次の自分の行動まで DEF +100%。その行動では移動しない。**周り2マス以内の味方も次の行動まで DEF +40%**（守りの陣。自分だけでは価値が薄かったため） | 2マス以内に敵2体以上、または 敵が2マス以内で周りに味方2体以上、または HP 50% 未満で敵が3マス以内 |
| 一斉指揮 | 300 | 4 | 自分と周囲3マスの味方の ATK +30% / DEF +15%（各自の行動2回分） | 周囲3マスに味方がいて、敵が6マス以内 |
| 一撃離脱 | 250 | 2 | 攻撃の前に使う。その行動の攻撃は反撃を受けず、攻撃の後に移動力いっぱい動ける（移動 → 攻撃 → 移動） | 攻撃できるとき |
| 遠隔狙撃 | 250 | 3 | その行動だけ射程 +1 | あと1マス届かない敵がいるとき |

- 強撃は当初 ×1.5 だったが、攻撃型の強さの主因は振り分け（ATK の多さ）で、強撃を弱めてもほぼ変わらなかった

### 士気（総大将の周囲） ✅🧪
- 総大将の周囲3マス以内にいる味方は、スキルとは別に常に ATK / DEF +5%（`MORALE_RANGE` / `MORALE_BONUS`）
- 一斉指揮（能動・大きめ）とは役割を分けている。総大将の位置が采配になる

### 固有能力（コスト消費） ✅🧪
| 能力 | コスト | 効果 |
|---|---|---|
| 足止め（ZOC） | 40 | 上下左右に隣接したマスに入った敵は、そこで移動が止まる |
| 突撃 | 20 | 上下左右いずれかに一直線に2マス以上走り、その直線上の隣の敵を攻撃すると、初撃の威力が「1 + 0.3 × 直進マス数」倍 |

### 兵種の相性（剣・槍・弓の三すくみ） ✅🧪
攻撃側 → 防御側のダメージ倍率。盾兵・騎兵には相性を付けず、ステータスで性格を出す。

| 攻撃側＼防御側 | 剣兵 | 槍兵 | 弓兵 |
|---|---|---|---|
| 剣兵 | — | ×0.85 | **×1.8** |
| 槍兵 | **×1.2** | — | ×0.85 |
| 弓兵 | ×0.55 | **×1.2** | — |

- 槍 → 剣: リーチで制す / 剣 → 弓: 詰め寄って斬る / 弓 → 槍: 鈍重な槍兵を射る
- 本来は「ステータス差で相性を出したい」方針。相性倍率は兵種の特徴を出しつつ調整しやすくするための補助
※Gemini 案（剣 10/12/8/10/1/9 など）は雑兵の弓兵（合計40）と兵長の槍兵・弓兵（102・84）の合計がコストと合っていなかったため、合計を揃えたうえでシミュレーションで調整した。

### ステータス値 → ゲーム内の値 ✅🧪

| 項目 | 換算 |
|---|---|
| 実HP | HP × 3（`HP_SCALE`） |
| 行動順 | SPD + 個体差（0〜2） |
| 移動力 | 雑兵換算の SPD ÷ 40、切り上げ（`MOVE_DIV`）。階級で足が速くなりすぎないよう、階級倍率で割り戻す |
| 攻撃頻度 | 行動ゲージ制（下記） |
| 命中率 | 兵種ごとの基本命中率 + 個体差 ±5% |

基本命中率: 剣兵 85% / 槍兵 80% / 弓兵 80% / 盾兵 80% / 騎兵 80%

## 5. バトル

### 1ターンの流れ ✅
1. 生存ユニットを SPD の高い順に並べる（同値はランダム）
2. 順に1体ずつ行動する。**1回の行動 = 移動1回 + 攻撃1回（順番は自由）**
   - 移動 → 攻撃、または 攻撃 → 移動（攻撃の後の移動は移動力の半分まで。間合いを取る用）
   - 攻撃1回の中の手数は行動ゲージで決まる（剣兵 1.6回など）
   - スキル「一撃離脱」なら 移動 → 攻撃 → 移動（攻撃の後も移動力いっぱい）
3. **反撃**: 攻撃された側は、攻撃してきた相手が自分の射程内にいれば撃ち返す（相手の1回の行動につき1回、威力は通常どおり、行動ゲージは使わない）。射程4の弓兵が射程4未満の敵を撃った場合などは届かないので反撃されない
4. ユニットが倒れるたびに勝利判定

### 攻撃頻度: 行動ゲージ ✅🧪
- 攻撃フェーズに入るたびに、ゲージに「雑兵換算の ACT」がたまる
- ゲージが 50（`ACT_PER_ATTACK`）たまるごとに1回攻撃（上限 100）
- **毎ターン最低1回は攻撃できる**（行動の始めにゲージが 50 未満なら 50 にする）。兵が減った駒や ACT の低い駒が「攻撃できる回数 0」で何もできないターンをなくすため。単一兵種どうしの勝率はほぼ変わらず
- 1行動あたりの平均攻撃回数: 剣兵 1.6 / 槍兵 1.2 / 弓兵 1.4 / 盾兵 1.0 / 騎兵 1.0
- Gemini 案の「ゲージ蓄積式」を採用。旧方式（ACT = 攻撃回数の整数）は 2→3 で火力が1.5倍に跳ね、細かい調整ができなかったため

### 命中・ダメージ ✅🧪
- 命中判定: 1d100 ≤ 命中率 × 距離の命中倍率 ＋ 回避補正（5〜99% に収める）
- **回避補正**（狙われた側の SPD）: 基準 SPD 100 から 10 違うごとに 1.5%。速い側は最大 −10%（避けやすい）、遅い側は最大 +5%（当たりやすい）
  - SPD・ACT は兵長も兵士の駒と同じ物差しで持つ（階級の倍率を割り戻す）。以前は兵長の SPD が 200 前後になり、行動順でいつも先頭・回避も最大になっていた（表示も将と桁が違って比べにくかった）
  - 割り戻して使わなくなった SPD・ACT のコスト（兵長なら半分）は HP・DEF 寄りに配り直す（重み HP 1 / DEF 1 / ATK 0.3。`SERGEANT_SPARE_ATK`）。コストの合計は1000のまま。兵長は「堅い隊の柱」
    - 例: 剣兵長 HP 933 / ATK 225 / DEF 254、槍兵長 HP 921 / ATK 217 / DEF 256
    - 元の比率で配ったときは剣→盾 53→74%、剣→弓 70→82% と剣に偏った。HP・DEF 寄りにして（250戦）剣→盾 58%、剣→弓 77%、剣→槍 29%、槍→騎 60%
  - 例: 斥候(170) −10% / 暗殺者(140) −6% / 騎兵(130) −4% / 剣兵(100) ±0 / 槍兵・弓兵(80) +3% / 盾兵(50) +5%（盾が弓に弱くなりすぎないよう上限 +5）
  - 単一兵種どうしの勝率（300戦）は導入前後でほぼ変わらず（剣vs騎 53→52%、弓vs盾 59→59%、盾vs騎 51→50%）
  - ログに「命中68%（鈍くて被弾+3）」のように表示
- **基本値 = max(ATK × 0.15, ATK − DEF × 0.5 + 1d6×10)**（ATK・DEF はバフ・士気込み）
- **ダメージ = max(10, 基本値 × 距離の威力倍率 × 相性 × 突撃 × 包囲)**（四捨五入）
  - **最低でも ATK の15%は通る**（`MIN_DAMAGE_RATE`）。以前は総大将（DEF 396）に雑兵（ATK 100）の攻撃が最低ダメージ10しか入らず、雑兵で総大将を削ることがほぼ不可能だった（約160発必要）。現在は1発15（約105発、包囲で短縮）
  - 当初 25% にしたが、総大将を削る力が「1発の威力」でなく「攻撃回数」で決まるため、手数の多い剣兵と安全な距離から撃てる弓兵が有利になりすぎた（剣→弓 79%、弓→槍 83%、剣→盾 77%）。15% で三すくみが適度に出る形にした
  - **包囲ボーナス**: 攻撃対象に上下左右で隣接している味方1体ごとに威力 +10%（攻撃者自身は数えない、最大 +40%）（`SURROUND_BONUS`）。囲んで削る采配を強くする
  - Gemini 案の「DEF を半分にして引く」式を採用。コスト制では ATK と DEF が同程度の大きさになり、DEF をそのまま引くとダメージが出なくなるため
- 1d6 の出目6はクリティカル（ATK × 1.5）

### 距離による命中・威力の変化 ✅🧪
平面（4方向移動のマンハッタン距離）向けに調整済み。

| 兵種 | 距離1 | 距離2 | 距離3 | 距離4 | 距離5 |
|---|---|---|---|---|---|
| 剣兵 | 命中×1.0 威力×1.0 | — | — | — | — |
| 槍兵 | 命中×0.9 威力×0.9 | 命中×0.85 威力×1.0 | — | — | — |
| 弓兵 | 命中×0.6 威力×1.0 | ×1.0 | ×1.0 | ×0.9 | ×0.7 |

- 弓兵: 近すぎると狙いにくい / 2〜3 が最大性能 / 遠いほど落ちる
- 槍兵の距離2の命中が低いのは、平面では斜め隣（距離2）からも突けて強すぎたため

### AI（オート時） ✅🧪
- 目標: 最も近い敵（同距離なら残りHPが少ない方）
- 突撃を持つユニットは、一直線に走り込める敵がいれば最優先で突撃する（最も長く走れる経路）
- 各兵種の「最適距離」（剣1 / 槍2 / 弓3）で敵を攻撃できる空きマス（＝攻撃位置。側面・背後を含む）のうち、最も近いものへ移動し、射程内なら攻撃
  - すでに味方が張り付いている敵を囲みに行く位置を少し優先する。同じ評価のマスは少しランダムに選ぶ
  - 以前は「最も近い敵との距離」だけで移動先を決めていたため、正面が味方で埋まると後ろで待つだけになり、試合が進むと縦一列（縦縞）に並びがちだった
- 射程で勝っていて、敵が最適距離より近ければ後退（引き撃ち）。後退できるのは移動力の半分まで（切り上げ）
- 後衛（弓兵）は、味方前衛のうち最も前にいる者より前に出ない
- 総大将は、配下の残存率が「出撃タイミング」を下回るまで本陣から動かない（射程内の敵には攻撃する）
  - 出撃タイミングは画面で陣営ごとに選べる: 全滅まで待機（初期値）/ 残り30% / 残り50% / 最初から（`ADVANCE_MODES`）
  - 総大将は雑兵を1撃で倒せるため、早く出るほど強い（下の記録）。NPC 戦の難易度・性格（慎重〜好戦的）の調整に使う想定

### 移動ルール ✅
- 上下左右の4方向
- 1マス1体。味方のマスは通過できるが止まれない。敵のマスは通過不可
- 敵の足止め（ZOC）範囲に入ったら、そこで移動が止まる

## 5.5 手動プレイ ✅🧪

### 流れ
1. モード「手動プレイ」で「編成」→ ダイスで両軍・マップが決まる
2. **総大将の振り分け**画面で、HP / ATK / DEF の比率（スライダー）、SPD・ACT の強化、射程+1、スキル2つを決める。「型から読み込む」で4つの型を下敷きにできる。自由枠・実際の能力値がその場でプレビューされる
3. 「戦闘開始」→ SPD 順にユニットが行動。CPU 軍は AI、プレイヤー軍の番では入力を待つ

### 1体の行動（プレイヤーの番）
- **移動**: 青いマスをクリック（移動しないことも可）。移動は AI と同じルール（4方向、味方は通過可・敵は不可、ZOC で停止）
- **攻撃**: 赤枠の敵をクリック。行動ゲージがたまっている回数だけ攻撃できる。移動前に攻撃すると、その場から攻撃して移動はなし
- **突撃（騎兵）**: 一直線に2マス以上移動し、その直線の先に敵がいれば、その敵への初撃に突撃ボーナス
- **スキル**: 操作パネルのボタン。鉄壁の構えは移動前のみ（使うと移動なし）、強撃は次の攻撃に乗る、遠隔狙撃はその行動の射程+1、一斉指揮はいつでも、一撃離脱は攻撃後に離脱先を選ぶ
- **行動終了**ボタンで次のユニットへ
- 手動では総大将の「出撃タイミング」設定は使わない（プレイヤーが決める）

### 自動保存
- 編成・振り分け決定・各ユニットの行動のたびに、ブラウザの localStorage に保存（キー `dice-senki-save-v1`）
- ページを閉じても、アプリを終了しても、開き直すと同じ状態から再開。プレイヤーの入力待ちならそのまま待ち、CPU の番なら自動で進む
- 「リセット」で保存も消える

## 5.5.1 わかりやすさの改善・布陣・移動力・盾兵の「庇う」 ✅🧪
- **移動力 +1**（`MOVE_BONUS`）: 最低2ではテンポが悪いため全員 +1（盾 3 / 槍・弓・将 3〜4 / 剣 4 / 騎 5）
  - 兵種どうし（単一兵種の軍、60〜80戦ずつ）: 平均ターン 20.3 → 17.4。強すぎた弓兵が下がった（弓→槍 87% → 72〜80%、弓→盾 80% → 57〜68%）。剣→騎 43% → 39〜60%（ぶれ大）
- **盾兵の固有能力「庇う」**（コスト0）: 攻撃する側と狙われた味方が同じ縦・横の直線上にいて、その間に盾兵がいれば、盾兵が代わりに攻撃を受ける（いちばん攻撃側に近い盾兵。反撃も同じ）。隣接した相手への攻撃には間がないので起きない
  - 導入後（移動力+1込み）の盾兵: 剣→盾 54%、弓→盾 57%（盾兵の勝率が上がった）
- **布陣の手直し**（手動プレイ）: 開戦前（「戦闘開始」を押す前）に、自軍の駒をクリック → 自陣（黄色の枠のマス）をクリックで移動。自軍の駒をクリックすると入れ替え
- **スキルのわかりやすさ**: 操作パネルにスキルの説明と待ち時間を常に表示（スマホでは title が見えないため）。一斉指揮は「範囲を表示」で効果範囲（紫）を表示。使ったときはログに効果と、効果を受けた駒の一覧を出す。バフがかかっている駒は盤面に ▲、パネルと名前の title に「ATK+30%（残2回）」のように表示
- **突撃（騎兵）**: 上下左右のどれか一方向へ**曲がらずに**2マス以上まっすぐ走り、その先（同じ直線上の隣）にいる敵を攻撃したときだけ。曲がった経路（前3・右1など）は突撃にならない。手動プレイでは突撃になる移動先をオレンジ色で表示
- 固有能力（足止め・庇う・突撃・索敵・隠密・暗殺）の説明も操作パネルに表示
- **槍兵の範囲攻撃「突き・薙ぎ払い」**（固有能力・攻撃1回分を使う）
  - 突き: 自分から見て一直線に並んだ敵2体（隣と、その奥）を同時に攻撃。手前 80% / 奥 50%（合計130%）
  - 薙ぎ払い: 周りの8マスのうち、ひと続きの3マス（例: 左・左斜め前・前。角を含む弧）に敵が**2体以上**いれば、まとめて攻撃。2体ならそれぞれ55%（兵長60%）、3体なら40%（兵長50%）。反撃は弧の真ん中の敵から（いなければ隣の敵）
    - 以前は「隣の敵と、その左右の斜めの敵の3体」だけで、オートでは40戦で0回。弧・2体からにして54回使うように
  - 普通に間合い2から1体を突く攻撃もそのまま使える。反撃は真ん中（突きは手前）の相手からだけ
  - 手動: 技のボタンを1回押すと当たる敵が盤面で黄色く光り（向きの矢印つき）、もう一度押すと実行。槍兵の番には使える条件を操作パネルに表示
  - オート: 移動できる範囲に、技の見込み（倍率×相性の合計）がふつうの攻撃の 1.2 倍以上になるマスがあれば回り込んで使う（敵の隣に出て反撃を受けるので、はっきり得なときだけ）。以前は間合い2から突くばかりで技をほぼ使っていなかった（40戦で突き1回 → 87回。薙ぎ払いは敵が横に3体並ぶ必要があり、まだほぼ出ない）
  - オート: 範囲攻撃の見込み（倍率×相性の合計）が普通の攻撃より大きければ使う。手動: 使えるときに操作パネルへ「🔱突き／🔱薙ぎ払い」ボタンが出る
  - 8方向を囲まれたときの回転切りは、槍兵は機動力がなく囲まれにくいので見送り（兵長・将のスキル候補）💡
  - 導入後の兵種どうし（80戦ずつ）: 剣→槍 19%、槍→盾 68%、槍→騎 75%、弓→槍 80%。単一兵種どうしでは大きくは変わらない（隊列を組んだ混成の敵に効く能力）
- **各兵種の固有能力**（決定・実装）: 兵士の駒と兵長で強さが少し違う（`lv(u)`。兵長の方が強い）
  | 兵種 | 固有能力 | 兵士の駒 | 兵長 |
  |---|---|---|---|
  | 剣兵 | 追撃: 敵を倒すと行動ゲージがたまる（攻撃1回=50） | +25 | +50 |
  | 槍兵 | 突き・薙ぎ払い（攻撃の範囲がスキル代わり） | 突き 80%/50%・薙ぎ 各40% | 突き 90%/60%・薙ぎ 各50% |
  | 弓兵 | 狙い撃ち: その行動で移動しなかったら命中アップ（反撃にも効く） | +5% | +10% |
  | 盾兵 | 堅守: 受けるダメージを軽減（足止め・庇うに加えて） | −15% | −25% |
  | 騎兵 | 突撃: 直進1マスあたりの初撃の威力上昇 | +30% | +40% |
  - 槍衾は見送り（槍兵は突き・薙ぎ払いで特徴を出す）
  - 狙い撃ちを +10%/+20% にすると弓→槍 89%・弓→盾 74% と弓が強すぎたので +5%/+10% に
  - **三すくみの調整**: 槍→剣 約75%・弓→槍 約72% に対して、剣→弓が 約58%（400戦ずつ）と低かった。弓は引き撃ちで剣を寄せ付けにくく、相性倍率の効きが小さい。剣→弓 1.3 → **1.8**、弓→剣 0.75 → **0.55** で 剣→弓 70%（1.6 / 0.6 では 65%）。三すくみがほぼ同じ強さ（70〜75%）になった
  - 導入後の兵種どうし（120戦ずつ・左の勝率）: 剣→槍 23% / 剣→弓 48% / 剣→盾 47% / 剣→騎 63% / 槍→盾 62% / 槍→騎 64% / 弓→槍 71% / 弓→盾 58% / 弓→騎 56% / 盾→騎 52%。平均 17.8ターン。盾兵が剣・騎とほぼ互角になった

## 5.6 視界・斥候・暗殺者 ✅🧪

### 視界（戦場の霧）
- 味方の誰かの視界に入っている敵だけが見え、狙える（**視界は軍全体で共有**）。CPU も同じ条件で動く
- 画面上部の「視界（霧）」で切り替えられる（初期設定はオン）
- 視界: 剣・槍・盾・騎・将 4マス / 弓 4マス（射程は5。最大射程で撃つには仲間の視界が要る）/ 斥候 7マス / 暗殺者 4マス
  - 弓の視界は戦術戦闘の盤面だけのもの。斥候の視界は戦略マップでも効く想定 📝
- 手動プレイ: 見えない敵は盤面にも表にも出ない（暗いマス＝視界の外）。見えない敵の動きはログにも出ない。オート観戦では見えない敵を半透明で表示
- 手動プレイの移動先（青いマス）と突撃マーク（オレンジ）は、見えている敵だけで計算する（以前は見えない敵のマスが穴になったり、その手前に突撃マークが出たりして位置が分かってしまった）。実際に動くと霧の中の敵に阻まれることがあり、そのときは本当に行けるマスのうち目的地にいちばん近いところで止まる（「🌫 霧の中の敵に行く手を阻まれた！」）
- 敵が見えないとき（オート）: 大将は本陣で待ち、ほかは索敵する。陣営ごとに「最後に敵を見た場所」と「見回ったマス」を覚えていて、
  ① 最後に見た場所（大将を優先）→ ② 長く見ていないマス（敵の本陣寄りを優先。6ターンたつと見回り直す・駒ごとに少しばらける）→ ③ 敵の本陣 の順に向かう
  （以前は敵の本陣へ向かうだけで、遠回りして逃げた大将を追いかけず本陣跡に集まり続けていた）
- 一撃離脱の離脱先: 視界の外まで逃げ去らず、敵が見える間合い（視界 − 1 マス）に留まる（以前は最も遠くへ逃げ、霧に消えて追いかけっこが終わらなかった）
- 突撃は見えている敵にしかできない

### 斥候（兵士クラスの単独の駒・人数なし）
- 視界 7、移動 5、戦う力は弱い（HP・ATK・DEF が低い）。隠密の敵も2マスまで見つけられる
- オートでは戦わず、最も近い敵から5マスの距離を保って視界を取る。敵は射程内にいるとき以外は斥候を後回しにする（延々と追いかけ回さないように）
- 大将の「配下が残っている間は本陣で待つ」判定には数えない
- 人数: 軍の編成で 1d4。ふだんの「編成」の戦闘では 0〜2人
- 仕事は2種類（決定）: ① 単独で動いて視界を取る ② 隊に所属して本隊との連絡役（戦略マップで実装） 📝

### 暗殺者（兵長クラスの単独の駒）
- **隠密**: 敵からは隣のマスまで近づかないと見えない（斥候なら2マス）。攻撃すると、次の自分の行動まで姿が見える
- **暗殺**: 将（兵長・副将・総大将）への威力 ×1.6、兵士の駒・斥候への威力 ×0.5
- オートでは**副将以上**（大将を優先）だけを狙って忍び寄り、攻撃する。兵長以下は相手にせず、見つかりにくい間合い（2マス、斥候からは3マス）を保って避ける。将が見えなければ、最後に将を見た場所 → 索敵の地点へ
- 人数: 勝負をひっくり返しすぎないよう、軍の編成で **1d4−1（0〜3人）**。ふだんの「編成」の戦闘では 1d6 で6が出たときだけ1人
- 検証（オート・視界あり、60戦）: 片方だけ暗殺者1人を足すと勝率 68%。同じコストの剣兵長1人を足した場合は 62%。総大将へのとどめは0回。オートではひっくり返しすぎてはいない（手動で狙うともっと効く）
- 視界の有無（オート30戦ずつ）: 視界あり 平均22.7ターン / なし 25.9ターン。時間切れなし

## 8.5 モードの構想 💡
### 育成（ハクスラ）モード
- **プレイヤーレベル**: 戦いで経験を得てレベルが上がると、ステータスポイントが増える
- ポイントで**総大将を強化**（振り分けの予算・スキル枠など）
- ポイントで**副将を育てる**。育てた副将は次の戦いにも連れて行ける（使い回し）。ダイスで決まる副将とは別枠の「子飼いの副将」
- フィールド（戦略マップ）で**スキル習得アイテム**などを拾って集める
- 保存はブラウザ（localStorage）で足りる。ダイスで決まる兵力との兼ね合い（育てすぎてダイスの不利を覆せすぎないか）は要調整
### 対人戦
- アカウント・サーバーは面倒なので避けたい。候補（サーバーなし・軽い順）:
  1. **ホットシート**: 1台の端末を交代で操作。視界（霧）があるので、交代時に画面を隠す「次の人に渡してください」画面を挟む
  2. **ターンの受け渡し（文通式）**: 自分のターンを終えると「対戦コード」（文字列やURL）が出て、LINEなどで相手に送る。相手が読み込んで自分のターンを進め、また送り返す。交互ターン制と相性が良い。サーバー不要。ずる防止（ダイスのやり直し）は、乱数の種をコードに含めて対策
  3. **P2P 接続（WebRTC）**: リアルタイムでつながるが、最初の接続に手間（コードの交換）がかかり、通信環境によってはつながらない
  4. 無料のクラウド（Firebase など）: 楽だがアカウント・設定が要る
- おすすめは 1 → 2 の順。どちらもサーバーなしで GitHub Pages のまま遊べる
- **ハクスラと対人は相性が良い**（育てた軍を誰かと比べたい・戦わせたい）。サーバーなしで両立する案:
  - **非同期対戦（軍コードの交換）**: 育てた総大将・子飼いの副将・編成を「軍コード」（文字列・URL）に書き出して送る。受け取った側は **CPU が操作する相手の軍** と戦う（スマホゲームの「防衛チームと戦う」形式）。結果は「戦果コード」で返せる
  - 公平さ: 対戦では「レベル上限」か「総コスト上限」をそろえる。兵力のダイスは対戦ごとに両者とも振り直し、育成の対象は総大将・副将・スキルに限る（ダイスの不利を采配で覆すコンセプトを保つ）
  - 改ざん対策: 読み込み時に上限超えを確認（完全には防げないので友達どうし前提）
  - 軍コードの形式は、のちに文通式の本当の対人戦（2.）にもそのまま使う。育成モードを作るときに最初から書き出せる形にしておく

### 総大将の型の差（将・スキル導入前） ⚠️
配下は両軍とも同じ（5兵種の混成10体）、総大将は両軍とも「将」で、型だけを変えたときの勝率（300戦ずつ）。

| 型＼相手 | バランス型 | 攻撃型 | 防御型 | 騎乗型 |
|---|---|---|---|---|
| バランス型 | 50% | 44% | 97% | 100% |
| 攻撃型 | 63% | 52% | 95% | 97% |
| 防御型 | 4% | 7% | 47% | 99% |
| 騎乗型 | 0% | 4% | 1% | 51% |

**検証した対策（計算による1対1の解析）**
| 対策 | 結果 |
|---|---|
| 上限・下限（自由枠の20〜50%） | 極端な型は防げるが、範囲内でも最強の型が残る（HP 492 / ATK 564 / DEF 264。DEF は下限） |
| 上限・下限 + DEF に振ると HP に補正（DEF 1 につき HP +0.25〜1.5） | 補正 0.5 までは最強の型がほぼ同じ。0.75 以上では「HP を下限まで削り DEF と ATK に振る」型が新たに最強になる。どの補正量でも防御型（ATK 20%）は最強の型に大きく負ける |

**原因（計算で確認）**: 総大将どうしの1対1は「相手を倒すまでの手数」の比べ合いで、手数は「自分の HP ÷ 相手の与ダメ」で決まる。ポイントの合計が一定だと、HP と ATK を半々に振り DEF を最低にする配分が、他のどの配分にも勝つ（減算型・比率型どちらのダメージ式でも、DEF の値段を変えても、最強の配分の位置が変わるだけで「最強が1つある」構造は変わらない）。ダメージのブレを大きくしても、型の差が大きすぎるため勝率はほぼ変わらなかった。
1対1は「耐久 × 与ダメ」の掛け算の勝負なので、ATK を削る型はどうしても勝てない。ステータスの換算だけでは解決できず、DEF や HP に1対1以外の価値（対雑兵、スキル、地形など）を持たせる必要がある。

## 9.z ダメージを比率型に・DEF の物差しを統一（大部隊と兵長・将の釣り合い）
- 問題: 旧式「ATK − DEF×0.5 + 1d6×10」では、DEF の高い兵長・将に兵士の駒の攻撃がほとんど通らず、剣兵300人（コスト換算3000）でも剣兵長（1000）に勝率5%、副将に0%だった

- **DEF は階級の倍率を掛けない**（兵長・将の DEF は兵士の駒と同じ物差し。HP と ATK だけが階級で伸びる）。DEF まで伸ばすと強さが階級の3乗になるため
- 兵長の「割り戻した SPD/ACT の分を HP/DEF に配り直す」はやめた（比率型＋DEF統一で、配り直すと兵長が副将並みに強くなったため）
- 1対1（各200戦）: 兵長 ≒ 剣兵 約140人分、副将（標準） ≒ 約205人分（剣兵150人 対 兵長 65%・対 副将 2%、200人 対 兵長 99%・対 副将 44%、250人 対 副将 94%）

## レアキャラ・新兵種の構想 💡
- 方針: 「何か一点がずば抜けていて、はっきりした弱点がある」。兵種の上位種としてのレア（剣士 → 二刀流剣士、盾兵 → 大盾 など）
- **軍師**（武器: 軍配団扇）: 本人は弱い。オートの賢さが上がるだけでは手触りが薄いので、目に見える「策」を持たせたい
  - 案: 伏兵（戦闘開始時に霧の中へ隠れた隊を置ける）／ 采配（周りの味方1体にもう一度行動させる）／ 偽報（敵の行動順を1つ遅らせる・敵の大将の待機を解く）／ 地形を読む（森・山の効果を味方だけ強める）／ 戦域図で隊の移動力 +1
- **大盾**（盾兵の上位種・レア）: 兵長の「範囲庇う」をここに。隣の味方への攻撃をまとめて受ける・正面からの矢を防ぐ。動きは遅い
- **狙撃手**: 攻撃範囲を直線（上下左右）に絞る代わりに、長距離・高威力。近寄られると何もできない
- ファンタジー要素（世界観の切り替えと合わせて）
  - **魔法使い**: 範囲攻撃・DEF をある程度無視（比率型の式で DEF の効きを弱める）。とても脆い
  - **シーフ**（攻撃寄りの斥候）: 背後からの一撃が強い・敵の強化やゲージを奪う・罠の解除や設置が得意
- **シーフ**（斥候の上位種）: 弓と短剣を持ち替えられる（持ち替えは行動の始めに。弓 = 射程3・短剣 = 近接で背後からの一撃が強い）。弓兵の弱点（近接）を自分で補える器用さが持ち味。代わりに脆く、どちらも本職には一歩劣る
- **INT（知力）**: 魔法の威力・魔法への抵抗に使う新しいステータス。今は将以外に使う駒がいないので、入れても既存の釣り合いは崩れにくい
  - 魔法のダメージ = INT × K ÷ (K + 相手の INT か DEF の一部) のような比率型（物理と別の防御）
  - 将にも振れるようにするなら、振り分けの枠（HP/ATK/DEF/INT）と自由枠の割合を見直す
  - INT があれば **魔法剣士**（ATK と INT の両方で戦う）も作れる
- **パラディン**（盾兵の上位種・剣＋盾）: 盾兵が何で攻撃しているかを「片手剣（短めの剣）＋盾」とはっきりさせたうえで、上位種は剣をしっかり振れる。受け流し＋反撃、INT があれば回復や味方の守り

## INT（知力）✅（枠だけ）
- ステータスに INT を追加（`STAT_KEYS`）。魔法の威力・魔法への抵抗に使う予定。今は INT を持つ兵種・将はいないので全員 0（詳細のポップアップに「INT —」）
- 兵種の表に `int` を書けば、コスト500の内訳に入り、階級の倍率でも伸びる（ATK と同じ扱い）
- 魔法のダメージ（予定）: INT × K ÷ (K + 抵抗)。抵抗は相手の INT と DEF の一部から
- 将が INT を振れるようにするのは、魔法系の将を作るときに（振り分けの枠と割合を見直す）
- 構想
  - **ヒーラー**: INT で回復量が決まる。攻撃は弱い
  - **軍師**（軍配団扇）: 本人の統率力が高い。総大将の本隊に入れると軍師の統率力を本隊に加える（分隊を率いるときも有効）。全軍へのバフ（どの隊にも）＋自分のいる隊への追加のバフ。バフの上がり幅に INT が乗る
- 出陣中の編成画面（見るだけ）も、隊のカードをタップで開き、将・駒の行をタップで今の状態（残りの人数・ステータス）をポップアップで見られる。カードには戦域図での位置と行動済みかも出す
- 守備隊（砦に駐留させた副将）は、砦の再編成で「隊ごと合流」できる（守りを解いて、副将がほかの隊の配下に戻る。元の隊でなくてもよい）。以前は守備隊だけ合流の選択肢がなく、戻せなかった

- 兵士の数と駒の大きさの見直し（兵士より兵長の駒が多くなりがちだったため）
  - 兵士のダイス 1d10×100 → **1d20×100**（100〜2000人）
  - 新しく作る駒は **100人以上**（`MIN_PIECE`）。おまかせ編成も100人未満の端数は配らず、ほかの隊に回す。戦闘で減った駒は10人まで残る
  - 率いる人数 統率1 = 100人分 → **200人分**。駒の数の上限（= 統率力）と士気は変えない
  - 測定（1対1・200戦）: 剣兵150人 ≒ 剣兵長（60%）、剣兵200人 ≒ 副将（46%）、250人で副将に93%。兵種どうしの勝率は変化なし（駒単位の強さは変えていないため）
- 兵長の余りのコストを HP / ATK に（`sergeantStats`・`SERGEANT_SPARE`）
  - 兵長はコスト1000で兵士の2倍のステータスを持つが、SPD / ACT は ÷2 して兵士と同じ物差しに戻している。浮いた分から SPD+10 の分を引いた残り（剣兵長 約180・槍 約130・弓 約140）の **半分** を、プリセットの HP:ATK の比で足す
  - 測定（1対1・200戦）: 剣兵長と互角になる剣兵の駒 約150人 → **約175人**。全部振ると約205人で副将（約200人）と並んでしまうため半分にした
  - 総大将・副将には余りはない（SPD / ACT などの固定枠を階級の倍率分のコストで払い、残りは全部 HP / ATK / DEF に振るため）
- 将の強化と兵長の残りを全部振る
  - 将（総大将・副将）の固定枠のうち **SPD / ACT は兵士と同じ値段**にした（`GENERAL_TEMPO_RATE` = 0。以前は階級の倍率どおり ×3〜4 で払っていた）。SPD / ACT は階級で伸ばさない値なので、兵長と同じ扱いにそろえた。射程・固有能力は今までどおり階級の倍率で払う。副将の自由枠 910 → 1230
  - 兵長は SPD / ACT 割り戻しの残りを **全部** HP / ATK に（`SERGEANT_SPARE` = 1）
  - 武器の割引を測り直し: 弓 55→35、槍 −15→−40、盾 −10→−25、馬 45→20、二刀（レア）40→−40
  - 測定（1対1・200戦。剣兵の駒と互角になる人数）: 兵長 約150 → **約210人**、副将 約200 → **約300人**（コスト比 1000:1500 とほぼ同じ）。副将 vs 兵長 99%
  - 武器（副将1人＋兵士6駒どうし・150戦、刀の副将の軍に対する勝率）: 刀45 槍58 弓54 盾57 馬51
  - レアの二刀流剣士: 通常の副将に 78%、剣兵300人に 95%・400人に 65%
- 将の SPD / ACT 強化: 上限 +50 → **+100**（`UPGRADE_CAP`）、値段を基本の SPD / ACT と同じ（階級の倍率なし）に。射程の強化は今までどおり階級の倍率
  - 以前の値段（副将 ×3）だと、強化した副将は標準の副将に 1対1 で SPD+50 で 20%、ACT+50 で 33% と、強化するほど弱くなっていた（上限を上げても意味がなかった）
  - 変更後（副将の1対1・300戦、標準の副将への勝率）: SPD+50 47%（移動+1）・SPD+100 37%（移動+2）・ACT+30 68%・ACT+50 64%・ACT+100 49%・両方+50 70%・両方+100 44%
